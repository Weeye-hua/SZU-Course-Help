## 无需 Python，完整解压后即可使用

本版本提供 Windows、macOS 和 Linux 原生发布包。普通用户请下载与自己系统匹配的 ZIP，不要下载 GitHub 自动附带的 Source code 压缩包。

## v3.7.2 更新说明

1. 整合并补强 [PR #16](https://github.com/Weeye-hua/SZU-Course-Help/pull/16)，解决 [Issue #15](https://github.com/Weeye-hua/SZU-Course-Help/issues/15)：本科生可在清单内按“学校开抢时间”或“自定义北京时间”预约，支持 30 秒至 7 天、倒计时、修改和取消。研究生暂不提供预约。
2. 学校时间从 `elective/batch.do` 的当前批次 `beginTime` 读取，严格匹配唯一批次。创建时改时间须重新确认，等待期间及到点会重新同步；时间缺失或无法确认时不盲目启动。
3. 学校、自定义模式都绑定原账号与批次，到点重新检查登录、允许阶段和启用的待抢课程。等待期间使用现有保活及 OCR 恢复策略，不跨账号重登，不绕过学校开放规则。
4. 补齐取消/启动竞争、注销后同账号重登、清单清空、手动启动、多页面修改与旧程序实例等边界。核验阶段仍可取消；已启动后使用“停止抢课”。浏览器刷新能恢复预约状态及自定义时间。
5. 北京时间使用固定 UTC+8，避免 Windows 打包时缺少时区数据库。HTTP Date 校时仅作参考，拒绝过慢、缓存、乱序与过期样本；电脑休眠错过目标超过 2 分钟不会自动补启动。
6. 保留研究生模式、主站直连及可选 WebVPN 只读备用、暂停/继续/停止、三种模式、自定义失败阈值与无限次选项、最多 50 次验证码尝试、连续 2000 次未知响应保护和严格成功复核。
7. 更新 README、Markdown/PDF 使用手册。继续提供 Windows、两种 Mac 芯片、Linux 与源码 ZIP，不附带独立 `.sha256` 或 `SHA256SUMS.txt` 文件，不包含邮件通知。

**使用边界：** 预约仅保存在本次程序内存中。请保持终端、本地服务和电脑运行，退出登录或关闭程序会取消预约，程序重启不恢复。预约不会保证抢到课程；到点仍无法确认学校状态时会失败并保留清单。

**验证边界：** 本轮回归及桌面/手机检查使用模拟时钟与学校响应，不执行真实学校选课或退课。各平台构建检查 OCR 初始化和本科生/研究生本地启动；实际资格与结果仍以学校官方系统为准。

## 首次运行

1. 完整解压 ZIP，不要在压缩包预览窗口内直接运行，也不要只拖出主程序。
2. 运行平台启动脚本，先选择本科生或研究生，再输入学号并生成本机 Card Key。
3. 输入 `Y` 后，程序会启动本地网页并打开登录页。
4. 首次登录由用户输入学校密码并完成验证码；本科生按顺序点击四个汉字，研究生填写四位字符（识别辅助结果需自行核对）。
5. 本科生只允许学校明确返回的复选、正选、补选或补退选批次；研究生要求当前处于学校允许选课的开放时段和策略。状态未知、未开放或已结束时均禁止启动，启动仍需二次确认。

## 数据与安全

- Windows 数据目录：`%APPDATA%\SZU-Course-Help\`。
- macOS 数据目录：`~/Library/Application Support/SZU-Course-Help/`。
- Linux 数据目录：`${XDG_DATA_HOME:-~/.local/share}/SZU-Course-Help/`。
- 研究生使用上述目录中的 `graduate` 子目录，清单进一步按账号隔离；不会读写本科生清单。升级请解压到新目录，并在退出旧程序后启动，勿同时运行多个真实选课任务。
- 学校密码、token 与 Cookie 不写入磁盘；关闭程序后必须重新手动登录。
- 当前版本未购买 Windows 或 Apple 商业代码签名证书，SmartScreen 或 Gatekeeper 可能显示未知开发者提示。
- 只从本仓库官方 Release 下载，不要运行群文件、网盘或陌生链接中的副本。
- 学校接口和规则可能变化，关键选课结果以学校官方系统为准。

完整步骤、任务暂停编辑、数据迁移、自动重登录和常见问题请阅读发布包中的 `使用手册.pdf`。
