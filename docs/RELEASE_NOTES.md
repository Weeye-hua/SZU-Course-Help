## 无需 Python，完整解压后即可使用

本版本提供 Windows、macOS 和 Linux 原生发布包。普通用户请下载与自己系统匹配的 ZIP，不要下载 GitHub 自动附带的 Source code 压缩包。

## v3.7.1 更新说明

1. 明确本科生主站 `http://bkxk.szu.edu.cn` 校内、校外通用，默认使用“自动”或“主站直连”。本次不是新增校外登录能力，旧版也直接连接相同主站。
2. 接入并补强 [PR #14](https://github.com/Weeye-hua/SZU-Course-Help/pull/14) 的可选 WebVPN 验证码修复。手动选择并完成网关认证后，同一轮验证码 token 和图片均使用该入口，避免不同入口混用。
3. 增强 WebVPN 认证过期识别：网关登录重定向和认证页面会显示重新认证提示，不再误当作验证码图片；清理失效网关授权时保留学校会话，避免旧响应清除新授权。
4. 区分学校未开放、网络异常与网关认证过期。切换入口会清除旧验证码和点击坐标，请求期间禁止重复切换与提交；普通错误仍可手动刷新，不会一律要求重新认证。
5. WebVPN Cookie 提取增加过期检查与域名边界校验。WebVPN 仅是验证码与只读查询备用，不是完整的登录或选课提交通道；学校登录、选课提交及 OCR 自动重登录仍走主站。
6. 保留研究生模式、暂停/继续/停止、三种模式、自定义失败阈值与无限次选项、最多 50 次验证码尝试、连续 2000 次未知响应保护，以及按教学班 ID 严格核验成功的策略。
7. 更新 Markdown/PDF 使用手册。Release 继续提供 Windows、两种 Mac 芯片、Linux 与源码 ZIP，不附带独立 `.sha256` 或 `SHA256SUMS.txt` 文件，本版不包含邮件通知。

**验证边界：** 本轮回归及桌面/手机页面检查使用离线模拟，不执行真实学校选课或退课，未进行完整 WebVPN 实网登录联调。各平台构建会检查 OCR 初始化和本科生/研究生本地启动；实际资格与结果仍以学校官方系统为准。

## 首次运行

1. 完整解压 ZIP，不要在压缩包预览窗口内直接运行，也不要只拖出主程序。
2. 运行平台启动脚本，先选择本科生或研究生，再输入学号并生成本机 Card Key。
3. 输入 `Y` 后，程序会启动本地网页并打开登录页。
4. 首次登录由用户输入学校密码并完成验证码；本科生按顺序点击四个汉字，研究生填写四位字符（识别辅助结果需自行核对）。
5. 本科生只允许学校明确返回的复选、正选、补选或补退选批次；研究生要求当前处于学校允许选课的开放时段和策略。状态未知、未开放或已结束时均禁止启动，启动仍需二次确认。

## 数据与安全

- Windows 数据目录：`%APPDATA%\SZU-Course-Help\`。
- macOS 数据目录：`~/Library/Application Support/SZU-Course-Help/`。
- Linux 数据目录：`${XDG_DATA_HOME:-~/.local/share}/SZU-Course-Help/`。
- 研究生使用上述目录中的 `graduate` 子目录，清单进一步按账号隔离；不会读写本科生清单。升级请解压到新目录，并在退出旧程序后启动，勿同时运行多个真实选课任务。
- 学校密码、token 与 Cookie 不写入磁盘；关闭程序后必须重新手动登录。
- 当前版本未购买 Windows 或 Apple 商业代码签名证书，SmartScreen 或 Gatekeeper 可能显示未知开发者提示。
- 只从本仓库官方 Release 下载，不要运行群文件、网盘或陌生链接中的副本。
- 学校接口和规则可能变化，关键选课结果以学校官方系统为准。

完整步骤、任务暂停编辑、数据迁移、自动重登录和常见问题请阅读发布包中的 `使用手册.pdf`。
