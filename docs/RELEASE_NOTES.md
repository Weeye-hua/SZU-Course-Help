## 无需 Python，完整解压后即可使用

本版本提供 Windows、macOS 和 Linux 原生发布包。普通用户请下载与自己系统匹配的 ZIP，不要下载 GitHub 自动附带的 Source code 压缩包。

## v3.7.0 更新说明

1. 新增研究生选课模式。启动时选择 `1 本科生` 或 `2 研究生`，同一个发布包可使用两种模式。
2. 研究生接入独立 `yjsxkapp` HTTPS 入口和四位字符验证码，支持手动首次登录、验证码识别辅助及会话过期后的 OCR 自动重登录。本科生原有点击验证码协议不变。
3. 新增研究生方案内课程、跨专业课程、已选课程与开课查询，支持关键词、院系及满员/冲突筛选。开课查询严格只读，不能直接加入抢课清单。
4. 研究生使用学校服务器时间、开放起止时间、开放标志及可选策略判断能否启动；不写死学期日期、不套用本科生阶段名称，“不可选可退”时禁止启动。
5. 研究生课表优先使用结构化星期/节次，未安排时间课程单独列出；详细课表不可用时回退已选课程文字安排并提示刷新，不套用本科生作息钟点。
6. 研究生复用暂停/继续/停止、三种模式、自定义失败阈值与无限次选项，保留最多 50 次验证码尝试及连续 2000 次未知响应保护。修复扫描目录时会话过期未进入自动重登录的问题。
7. 保留严格选课成功核验：提交成功只是候选结果，必须在学校已选列表中精确匹配教学班 ID，才会确认抢到；核验异常时保护性暂停。
8. 本科生与研究生运行数据分开，研究生清单按账号隔离，缓存按账号、轮次和筛选条件隔离；研究生不提供本科生 WebVPN、校区切换或退课入口。
9. 更新 Markdown/PDF 使用手册。Release 继续提供 Windows、两种 Mac 芯片、Linux 与源码 ZIP，不附带独立 `.sha256` 或 `SHA256SUMS.txt` 文件。本版不包含邮件通知。

**验证边界：** 自动测试使用模拟响应并拦截未模拟的外部请求；真实学校联调仅验证登录、目录、已选课程和课表读取，没有使用测试账号执行真实选课或退课。实际资格与结果仍以学校官方系统为准。

## 首次运行

1. 完整解压 ZIP，不要在压缩包预览窗口内直接运行，也不要只拖出主程序。
2. 运行平台启动脚本，先选择本科生或研究生，再输入学号并生成本机 Card Key。
3. 输入 `Y` 后，程序会启动本地网页并打开登录页。
4. 首次登录由用户输入学校密码并完成验证码；本科生按顺序点击四个汉字，研究生填写四位字符（识别辅助结果需自行核对）。
5. 本科生只允许学校明确返回的复选、正选、补选或补退选批次；研究生要求当前处于学校允许选课的开放时段和策略。状态未知、未开放或已结束时均禁止启动，启动仍需二次确认。

## 数据与安全

- Windows 数据目录：`%APPDATA%\SZU-Course-Help\`。
- macOS 数据目录：`~/Library/Application Support/SZU-Course-Help/`。
- Linux 数据目录：`${XDG_DATA_HOME:-~/.local/share}/SZU-Course-Help/`。
- 研究生使用上述目录中的 `graduate` 子目录，清单进一步按账号隔离；不会读写本科生清单。升级请解压到新目录，并在退出旧程序后启动，勿同时运行多个真实选课任务。
- 学校密码、token 与 Cookie 不写入磁盘；关闭程序后必须重新手动登录。
- 当前版本未购买 Windows 或 Apple 商业代码签名证书，SmartScreen 或 Gatekeeper 可能显示未知开发者提示。
- 只从本仓库官方 Release 下载，不要运行群文件、网盘或陌生链接中的副本。
- 学校接口和规则可能变化，关键选课结果以学校官方系统为准。

完整步骤、任务暂停编辑、数据迁移、自动重登录和常见问题请阅读发布包中的 `使用手册.pdf`。
